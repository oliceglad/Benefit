## Маршрутизация (GOAT)
1. Для каждой задачи программирования сначала вызывай агента triage.
2. Передай задачу агенту соответствующего маршрута: quick, build или deep. Передай полную задачу и JSON от triage. Никогда не передавай параметр model вручную.
3. Затем вызови verifier, передав риск и проверки от triage.
4. Если verifier вернул FAIL, повтори один раз, на одну ступень выше:
   - пропущен файл или не запущены тесты → больше рассуждений (quick → build)
   - был полный контекст, но результат неверен → более мощная модель (build → deep → escalate)
5. После любого повышения уровня попроси triage сохранить в файле ROUTING-LESSONS.md одну строку: "<тип задачи> → <маршрут, который сработал>".
