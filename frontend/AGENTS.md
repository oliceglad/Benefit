# Frontend Benefit

## Scope

This directory contains the only browser application for Benefit. Backend code,
gateway rules and infrastructure are outside the frontend scope and must not be
changed from frontend tasks.

## Stack and commands

- React, strict TypeScript and Vite.
- TanStack Router and TanStack Query.
- React Hook Form with Zod.
- OpenAPI clients generated by Orval.
- Tailwind CSS and local shadcn/ui components built on Radix.
- pnpm is the package manager; keep `pnpm-lock.yaml` committed.

Run from `frontend/`:

```bash
pnpm install --frozen-lockfile
pnpm api:generate
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm dev
```

## Structure and dependency rules

- `src/app` owns bootstrap, providers, query client and route composition.
- `src/app/router.tsx` contains route-level composition only.
- `src/features` contains product behavior. A feature may import `shared`, but
  must not import another feature's private files.
- `src/shared/ui` contains API-independent primitives.
- `src/shared/api/generated` is produced by Orval and is never edited manually.
- `src/shared/api/transport` owns gateway access, Bearer headers and errors.
- `src/shared/session` is the only place allowed to hold access/refresh tokens.
- `shared` must never import `features` or `app`.

## API and session rules

- Browser requests use same-origin `/api` paths through the Vite proxy in
  development. Never hardcode `localhost:8000` in components.
- Keep access and refresh tokens in memory. Until the backend provides an
  HttpOnly-cookie/BFF contract, a page reload intentionally requires login.
- A 401 may trigger at most one shared refresh operation and one request replay.
- Do not retry login, refresh, logout or other mutations automatically.
- On logout or terminal refresh failure, clear private TanStack Query data.
- Preserve `AbortSignal`; support JSON, FormData and binary responses.

## UI donors

`../../ui-reference` is read-only reference material, not a dependency.

- Never import from it, symlink to it, add `file:` packages, or configure Vite
  filesystem access to it.
- Copy only the selected source into this repository, adapt it to Benefit tokens
  and record the exact path, commit and license in
  `docs/component-sources.yaml` and `THIRD_PARTY_NOTICES.md`.
- Do not copy Clerk, demo authentication, fake dashboards, donor logos or sample
  photography.
- Do not use gradients in backgrounds, components or decorative elements.
- The application must install, test and build after `ui-reference` is removed.

## Definition of done

- Relevant success, loading, validation, error, forbidden and rate-limit states
  are implemented.
- Keyboard focus is visible, labels are associated, and the changed screen works
  at 360 px width with long Russian text.
- `typecheck`, `lint`, `test` and `build` pass.
- Generated code is reproducible from committed OpenAPI files.
- The changed scenario is checked against the live gateway when available; mock
  results are reported separately.
