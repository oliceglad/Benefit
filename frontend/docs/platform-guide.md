# Знакомство с Benefit

По запросу 11.10.2026 добавлен добровольный анимированный гид поверх текущей
страницы кабинета. Новые маршруты, серверные операции и зависимости не добавлены.

## Запуск

Нажатие на Benefit открывает меню. Пункт «Знакомство с платформой» запускает
тур из пяти шагов. При загрузке страницы, входе и обычном нажатии на логотип
тур автоматически не открывается. Повторный запуск доступен тем же способом.
Прохождение не сохраняется и не связано с серверным онбордингом профиля.

Содержимое зависит от роли: кандидат знакомится с профилем, подтверждением
грейда, вакансиями и сообщениями; работодатель — с банком кандидатов, ФСП,
потребностями, вакансиями, пайплайнами и сообщениями. Тексты описывают имеющиеся
возможности и не обещают ещё не реализованный интерфейс приглашений.

## Поведение и оформление

`features/platform-guide` содержит тексты, SVG-композицию и окно гида.
`app/layouts` подключает единый компонент в обеих ролях. Иллюстрация повторяет
форму знака Benefit: основные линии синие, акцент красный, поверхности белые.
Линии и карточки появляются при смене шага; бесконечного движения нет.
`prefers-reduced-motion` отключает анимацию и сразу показывает линии целиком.

Использован нативный модальный `dialog`: фон недоступен для взаимодействия,
прокрутка страницы временно блокируется. Заголовок получает фокус при смене
шага; Tab/Shift+Tab остаются внутри окна. Escape, крестик, «Пропустить» и
«Начать работу» закрывают гид и возвращают фокус на Benefit. Можно перейти
назад или сразу к любому шагу через полоску прогресса.

Гид не меняет URL, не размонтирует текущую страницу, не сохраняет поля,
не публикует профиль и не запускает тестирование кандидата.

## Проверка

- Два целевых UI-теста: отдельный выбор в меню, закрытие и возврат фокуса,
  цикл Tab/Shift+Tab, содержание кандидата, завершение и повторный запуск.
  В jsdom заменены только отсутствующие методы нативного dialog.
- В desktop Chromium: запуск работодателя, смена шага, Escape, повторный запуск,
  нативная модальность, цикл фокуса и завершение. Незавершённый ввод в фильтре
  остался после закрытия; URL не изменился.
- Build/TypeScript и lint. Полный регресс и мобильная проверка отложены по
  действующим ограничениям хакатона. Кандидатская версия проверена UI-тестом,
  без смены текущего аккаунта в живом браузере.

Порядок P0 остаётся прежним: следующая продуктовая итерация — приглашения из
существующей карточки кандидата.
